# YOLOv5 Experiments

A repo tracking experiments in fine-tuning YOLOv5 and converting model weights to RKNN format.

Based on examples from [rknn\_model\_zoo](https://github.com/airockchip/rknn_model_zoo).

RKNN Model Zoo relies on [RKNN-Toolkit2](https://github.com/airockchip/rknn-toolkit2) for model conversion.
